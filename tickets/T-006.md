# T-006 — Ask Alba working without the key

## Description
Ask Alba chat UI and its seed knowledge file with the five pre-tested Q&As. Applies the guardrails: answers in the language asked, names a source, red-flag symptoms get 'llama a tu medico ahora' with no reassurance, low mood gets the TLC-MAMA hotline, unsure gets 'preguntale a una promotora o en el Circulo', and every health answer ends with the disclaimer. Works with no API key by returning seed answers; falls back to the seed answer after 5 seconds.

Spec: REQ-34, 35, 36, 37, 38, 39, 40 (docs/SPEC.md)

## Acceptance criteria
- [x] Answer names a source and follows the language of the question (AC-52, AC-54, AC-55)
- [x] A red-flag description gets 'llama a tu medico ahora' and no reassurance (AC-56)
- [x] A sad/cannot-sleep question names the TLC-MAMA hotline (AC-57)
- [x] An unsure answer says 'preguntale a una promotora o en el Circulo' (AC-58)
- [x] Every health answer ends with the disclaimer (AC-60)
- [x] Seed file holds the five Q&As of D2:L14-L18 (AC-61)
- [x] A slow or failed call on a live question shows the seed answer after 5 seconds (AC-71)
- [x] build + tests green (gates not yet run)
